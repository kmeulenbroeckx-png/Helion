# Helion Research website (concept)

Static site: plain HTML, CSS and JS. No build step.

- Pages: index.html, about.html, contact.html, mystery-shopping.html, retail-auditing.html, exit-interviews.html
- Store-entrance film: image sequence in assets/seq/d (desktop) and assets/seq/m (phone)
- GEO files: llms.txt, robots.txt, sitemap.xml
- The contact form posts to an n8n webhook that e-mails info@helionresearch.com.
